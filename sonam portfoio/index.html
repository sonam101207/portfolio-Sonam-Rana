Blind Stick — Arduino-Based Assistive Device

Blind Stick is an assistive-device prototype designed to help visually impaired people detect nearby obstacles. We built a stick using Arduino and related electronic components. When an obstacle is detected, the system provides feedback through a buzzer and a vibration motor.

Key Features:

  • Detects nearby obstacles using electronic sensors.
  • Provides audible alerts through a buzzer.
  • Provides tactile vibration feedback through a motor.
  • Demonstrates practical use of electronics and basic IoT concepts.
  • Focuses on accessibility and everyday problem-solving.

AgriLink — Farmer-to-Customer Website

AgriLink is a website concept we developed during a hackathon to connect farmers directly with customers. The project explores how a digital platform can help farmers present their agricultural products and make it easier for customers to connect with them.

Key Features:
