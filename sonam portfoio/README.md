## 🌐 Free Deployment via GitHub Pages

1. Push this folder to a GitHub repository named `sonam-portfolio` (or `<your-username>.github.io`).
2. Go to your repository's **Settings** > **Pages**.
3. Under **Build and deployment > Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your live portfolio will be available at:
   `https://<your-username>.github.io/sonam-portfolio/`
